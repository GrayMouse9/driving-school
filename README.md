# Автошкола с говорящими знаками

Браузерная многопользовательская 3D-игра на three.js: ученики ездят по общему городу и изучают ПДД с помощью адаптивных знаков-персонажей.

Статус: реализована первая 3D-сцена и клиентский адаптер предложения v0.1. Сервер, реальные сохранения, ИИ и мультиплеер пока не интегрированы.

## Команда и срок

Три Даши в аудитории: три ноутбука. Аня — бэкенд, работает удалённо.
Демонстрация: 31 октября 2026, 18:00 МСК.
Один ноутбук в аудитории запускает сервер, БД и ИИ. Он также может открыть клиент в браузере.
На двух других ноутбуках нужен только браузер.

## Два обязательных показа

1. LAN/Wi-Fi: сервер и три браузера в одном городе.
2. Полностью автономно: выключить Wi-Fi на серверном ноутбуке, игра продолжает работать через http://localhost:3000.

Серверный браузер с самого начала открывает localhost. Удалённые браузеры используют IP ноутбука-сервера.
ИИ и БД не должны обращаться к Аниному компьютеру или внешним сервисам.

## Структура

- client/ — 3D-клиент, управление и интерфейс.
- server/ — бэкенд, локальные агенты, сохранение.
- shared/ — общие форматы.
- content/ — серверный мир, знания и задания.
- docs/ — договорённости и запуск.
- references/ — визуальные референсы.

Запуск клиента: `cd client`, `npm ci`, `npm run dev`, затем http://localhost:5173.
Без сервера доступна только явно обозначенная проверка 3D. Подробности и передача команде: [интеграция клиента](docs/client-integration.md).
Production-сборка: `npm run build` в client/. Это ещё не готовая многопользовательская игра.

## Работа с Git

Общая ветка main должна оставаться пригодной для интеграции.
Предлагаемые ветки: feat/game-client, feat/ui, feat/content, feat/backend.
Схемы протокола менять вместе с клиентом и сервером.
Не добавлять в Git зависимости, локальную БД и секреты.
