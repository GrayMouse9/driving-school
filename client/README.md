# Клиент

Владелец: Даша 1 + Codex. UI: Даша 2.
Источник интеграции: ../docs/protocol.md.
three.js, вид от первого лица, управление и потоковая загрузка. Не включать полный мир или знания агентов в клиентский бандл.

## Первая реализация

```bash
npm ci
npm run dev
npm test
npm run build
```

Открыть http://localhost:5173. Без бэкенда доступна явно обозначенная
«Проверка 3D без сервера». Управление: WASD, пробел — тормоз, E — войти/выйти,
мышь после щелчка по сцене, Esc — освободить курсор.

Production-файлы: `dist/`; их должен раздавать сервер Ани на одном origin
с `/api` и `/ws`. [Интеграция и текущие ограничения](../docs/client-integration.md).
