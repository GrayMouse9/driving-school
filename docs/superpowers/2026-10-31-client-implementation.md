# Реализация клиентской части

Действующий план: ../today-plan.md; контракт v0.1: ../protocol.md (ещё не подтверждён).
Рабочая папка по уточнению пользователя: /home/dasha/files/sem5/hahaton.

1. Первая сцена: three.js, салон, WASD, тормоз, пеший режим, простые модели.
2. Изолированный HTTP/WS-адаптер: проверка сессии до WS, authoritative snapshots, события UI.
3. Загрузчик серверных участков с отменой устаревших запросов, ограничением байтов и dispose.
4. Временная минимальная оболочка вне src/ui, чтобы не занимать файлы Даши 2.
5. Тесты управления, бюджета и авторизации; сборка; браузерная проверка.

Локальный preview — только тест сцены, без авторизации, сохранений, ИИ или мультиплеера.
Полный город и знания не входят в bundle. Сетевой контракт не меняем.
Ресурсы участков пока поддерживаются только пустым списком: непустой список отклоняется явно.
Без размеров до ответа API нельзя доказать резервирование входящих байтов: это блокер
строгой проверки 10%, требующий согласования с Аней, а не молчаливого изменения контракта.
